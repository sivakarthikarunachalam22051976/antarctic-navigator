# Real-data directory

`raw/` is for downloaded source files such as NSIDC NetCDF and the current USNIC CSV. It is ignored by Git.

`historical/byu_v8.0/` is for the BYU/NIC historical validation database. It is ignored by Git.

`navigator_bundle.json` is the compact processed bundle used by the API. For the SIH prototype deployment, commit this file so Render can receive the updated processed data through GitHub.
